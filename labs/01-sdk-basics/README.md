# Lab 01 — ServiceNow SDK Basics

## Goal
Prove a local VS Code → ServiceNow SDK/Fluent → PDI → Git workflow.

## Build
A small scoped application.

Suggested minimum:
- one custom table,
- one role/security decision,
- one small server-side behavior,
- one testable function,
- README and ADR.

## Learning Objectives
- SDK project structure
- Fluent metadata
- local build/lint
- PDI install/deploy
- source control
- rollback/reinstall
- provider comparison

## Human Gate
Review architecture before implementation and inspect every generated metadata diff.
