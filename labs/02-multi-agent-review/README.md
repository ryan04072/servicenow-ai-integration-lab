# Lab 02 — Multi-Agent Implementation + Independent Review

## Goal
Implement the same bounded ServiceNow task with one provider and review it with another.

Example:
- Claude implements,
- Codex reviews,
- Gemini designs adversarial tests,
- Copilot checks repository/documentation impact,
- human decides.

Measure:
- defects found,
- false positives,
- human corrections,
- time,
- explanation quality.
