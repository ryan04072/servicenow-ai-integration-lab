# Lab 07 — AI Control Tower

## Objective

Take one personal AI capability and manage it as though it were entering an
enterprise lifecycle.

## Build

Choose an existing capability, for example:
- intelligent intake;
- ServiceNow discovery;
- executive brief;
- identity simulator.

Then:

1. identify/register the AI asset;
2. assign owner;
3. record capability ID;
4. link repo/config;
5. capture provider/runtime;
6. record autonomy stage;
7. define kill switch;
8. run the capability;
9. capture usage/cost/value evidence;
10. retire or promote it.

## Success

You can answer:

- What is this AI asset?
- Who owns it?
- What capability does it invoke?
- What data/tools does it use?
- How is it disabled?
- What does it cost?
- What value did it create?
- How would I retire it?
