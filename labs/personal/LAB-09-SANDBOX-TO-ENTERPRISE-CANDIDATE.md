# Lab 09 — Sandbox → Enterprise Candidate

## Objective

Build a generic ServiceNow feature using the unrestricted personal AI/toolchain,
then package it as though it were being proposed for enterprise adoption.

## Example

Build an Employee Center component using:
- design/frontend agent;
- Codex or Claude Code;
- ServiceNow PDI;
- ATF/manual tests.

Then:

1. remove personal/test data;
2. export update set/application XML;
3. run the ServiceNow Promotion Reviewer;
4. fix blockers;
5. create the Enterprise Candidate package;
6. simulate enterprise DEV Preview findings;
7. document what would change in the work environment.

## Learning goals

- distinguish build tooling from runtime dependencies;
- build portable ServiceNow configuration;
- understand update-set/app packaging;
- practice static XML review;
- identify environment-specific references;
- understand where enterprise SDLC begins.
