# Lab 10 — ServiceNow Build Agent

## Objective

Use Build Agent to implement one complete ServiceNow capability and capture
evidence about its planning, build, test, review, and documentation behavior.

## Recommended first benchmark

Build a small scoped application containing:
- intake table/form;
- simple approval;
- Flow;
- one role/ACL;
- ATF coverage;
- documentation.

## Process

1. Write normalized requirement.
2. Save starting-state evidence.
3. Give Build Agent one comprehensive initial prompt.
4. Review its plan.
5. Approve only expected script executions.
6. Record calls consumed.
7. Review artifacts.
8. Run tests/ATF.
9. Ask Build Agent to address identified defects if call budget permits.
10. Run ServiceNow Promotion Reviewer.
11. Record final result.

## Stretch

Rebuild the same normalized requirement using a different engineering tool and
compare evidence.
