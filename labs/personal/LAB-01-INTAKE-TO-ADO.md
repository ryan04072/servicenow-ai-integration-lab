# Lab 01 — Natural Language Intake → Azure DevOps

Build a pipeline that:
1. accepts a natural-language request;
2. asks only missing questions;
3. returns structured requirement JSON;
4. drafts acceptance criteria;
5. creates a personal Azure DevOps work item after approval;
6. records correlation ID and run trace.

Stretch:
- duplicate detection;
- roadmap classification;
- model-cost tracking.
