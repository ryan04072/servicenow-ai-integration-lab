# Lab 08 — Copilot ↔ AI Control Tower Reconciliation

## Objective

Use the personal Copilot + AI Control Tower environment to learn external-AI
discovery and reconciliation.

## Steps

1. Identify a known Copilot agent/capability.
2. Record its expected metadata manually.
3. Review what AI Control Tower discovers.
4. Compare:
   - name;
   - owner;
   - provider/platform;
   - lifecycle;
   - data/tool context;
   - status.
5. Reconcile known vs discovered representation.
6. Record missing/ambiguous metadata.
7. Decide:
   - managed;
   - reference-only;
   - duplicate;
   - retirement candidate.
8. Capture lessons.

## Stretch

Expose one ServiceNow lab capability to Copilot and document:

```text
Copilot experience
→ governed tool / MCP / API
→ ServiceNow capability
→ run evidence
→ AICT inventory
```

Then compare what each platform sees.
