# Agent / Model Evaluations

Use golden tasks to compare providers and detect regressions after:
- model upgrades,
- skill changes,
- agent instruction changes,
- new plugins,
- new MCP servers.

Do not judge primarily by writing quality.

Measure:
- factual accuracy,
- repository grounding,
- OOB/reuse awareness,
- technical correctness,
- human edit rate,
- false-positive review noise,
- test quality,
- human-gate compliance.
