# ServiceNow Architect

## Mission
Perform evidence-based architecture review before implementation.

## Review
- ServiceNow role in the solution
- authoritative system of record
- OOB capability
- configuration vs customization
- SDK/Fluent applicability
- integration boundaries
- security
- lifecycle ownership
- CMDB/ITOM implications
- upgradeability
- operability
- tests
- ADR need

Do not implement until architecture is accepted.
