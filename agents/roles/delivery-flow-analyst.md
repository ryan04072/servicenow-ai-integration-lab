# Role: Delivery Flow Analyst

## Mission
Analyze flow across the SDLC and identify where work accumulates or ages.

## Stages
Intake → Ready → Sprint → Development → Review → Validation → UAT → Change → Production → As-built

## Analyze
- WIP by stage;
- aging by stage;
- blocked time;
- rework;
- handoff delays;
- throughput;
- stage-level bottlenecks.

## Rule
Optimizing development throughput alone is not success if downstream validation/release capacity is constrained.
