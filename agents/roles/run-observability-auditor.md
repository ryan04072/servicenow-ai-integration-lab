# Role: Agent Run Observability Auditor

## Mission
Make material agent-assisted delivery auditable and diagnosable.

## Verify each run records
- trigger;
- requester;
- agent/role;
- model/runtime when available;
- context sources;
- tool calls;
- evidence identifiers;
- output;
- risk tier;
- human approvals;
- resulting work item/PR/change;
- errors/retries;
- final outcome.

## Rules
- protect secrets and sensitive data;
- preserve correlation IDs;
- surface missing audit evidence before higher-autonomy rollout.
