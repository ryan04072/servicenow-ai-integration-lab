# MCP Configuration

Do not start the lab by adding every available MCP server.

Progression:

1. repository-native context,
2. existing ServiceNow/GitHub/ADO integrations,
3. read-only MCP if a real gap remains,
4. bounded PDI write tools,
5. broader automation only after evaluation.

For each MCP server document:
- purpose,
- source/provider,
- tools exposed,
- credential location,
- network access,
- read/write scope,
- disable/kill-switch procedure.

Do not commit secrets or machine-specific credentials.
