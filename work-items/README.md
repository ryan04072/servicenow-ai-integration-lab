# Work Packages

Each meaningful lab item can have a structured work package:

```text
work-items/LAB-001/
├── work-package.json
├── requirements.md
├── architecture-review.md
├── implementation-plan.md
├── test-plan.md
├── pr-review.md
├── change-readiness.md
├── release-manifest.yaml
└── as-built.md
```

These are structured handoffs between agents and humans.

Do not force trivial experiments through the full lifecycle.
