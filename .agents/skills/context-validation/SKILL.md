# Context Validation


Before material recommendations:
1. identify the actual question,
2. search repository evidence,
3. inspect relevant architecture/ADR/project/source,
4. identify conflicts or stale material,
5. separate fact/recommendation/unknown,
6. do not create new structure before checking existing authoritative homes.
