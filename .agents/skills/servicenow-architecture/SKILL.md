# Servicenow Architecture


Assess:
- OOB capability
- system-of-record / orchestration role
- configuration before code
- global/scoped considerations
- SDK/Fluent applicability
- integration boundaries
- security/least privilege
- lifecycle ownership
- ITOM/CMDB implications
- operability
- testing
- ADR need

Output facts, options, recommendation, risks, and validation steps.
