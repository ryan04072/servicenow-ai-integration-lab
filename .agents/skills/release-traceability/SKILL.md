# Release Traceability


Maintain one correlation chain across:
- ServiceNow intake
- Azure DevOps work item
- GitHub branch
- GitHub PR
- build/test run
- ServiceNow change
- release version
- documentation update

Use work-package and release-manifest contracts.
Never guess missing identifiers.
