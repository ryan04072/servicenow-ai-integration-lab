# Servicenow Code Review


Review for:
- correctness
- supported ServiceNow APIs
- OOB alternatives
- GlideRecord/query safety
- ACL/security
- secrets
- errors/recursion
- performance
- reuse
- hard-coded values
- upgradeability
- tests

Classify: Blocker / Important / Improvement.
