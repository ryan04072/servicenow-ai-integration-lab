# Community Skill Review


Before adopting an external skill/plugin:
- inspect SKILL.md/instructions,
- inspect scripts/hooks,
- inspect network calls,
- inspect MCP definitions,
- inspect permissions,
- inspect package installs,
- inspect environment/secret access,
- inspect license/source/update mechanism.

Test in isolation before canonical adoption.
