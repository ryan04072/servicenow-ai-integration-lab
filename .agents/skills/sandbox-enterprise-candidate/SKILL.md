# Skill: Sandbox → Enterprise Candidate

Use this skill after a personal ServiceNow experiment works and may be useful at
work.

1. Freeze a known-good sandbox version.
2. Remove test data and personal secrets.
3. Export the ServiceNow package/update set.
4. Capture a package hash.
5. Inventory artifacts.
6. Document dependencies.
7. Document external build-tool provenance.
8. Scan portability risks.
9. Run the ServiceNow Promotion Reviewer.
10. Package the review + XML + tests + architecture as an Enterprise Candidate.
11. Do not present the candidate as approved for enterprise use.
12. If adopted, enterprise DEV becomes the start of the normal enterprise SDLC.
