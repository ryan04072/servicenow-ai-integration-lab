# Skill: AI Workload Routing

For a proposed AI use case:

1. identify authoritative system;
2. identify user experience;
3. determine search/reasoning/analytics/action;
4. determine required tools/context;
5. prefer OOB/native AI;
6. route to ServiceNow, Microsoft, GitHub, or cross-platform orchestration;
7. record why;
8. estimate governance/cost/support implications.
