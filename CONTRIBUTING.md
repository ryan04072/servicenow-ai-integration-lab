# Contributing

This is a personal lab, but use professional habits.

## Branching
Use a feature branch for meaningful changes.

## Pull Requests
For significant changes include:
- objective
- work package / ADO linkage if applicable
- architecture impact
- tests
- documentation impact
- rollback/recovery
- human review notes

## AI-Generated Changes
AI-generated code/configuration is treated exactly like human-generated work:
- inspect diff,
- test,
- review,
- document durable changes.
