# Personal Lab — Documentation Agents

For one completed capability, have the documentation router generate four
different artifacts from the same evidence:

1. GitHub technical as-built.
2. Fulfiller-facing ServiceNow KB/QRG.
3. Operational runbook.
4. Architecture Decision/Rationale Record.

Compare them for:
- audience fit;
- duplication;
- unsupported claims;
- missing evidence;
- maintainability.

The goal is not maximum documentation volume. It is **correct information in the
correct canonical place**.
