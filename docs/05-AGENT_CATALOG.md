# Agent Catalog

| Role | Job | Writes by Default | Human Gate |
|---|---|---|---|
| Orchestrator | Route lifecycle | Work-package history | At defined states |
| Intake Analyst | Requirements | Draft evidence | Human review |
| ServiceNow Architect | Architecture | Draft evidence | Architecture acceptance |
| Backlog Engineer | Story/task structure | Draft evidence | ADO review |
| Portfolio Advisor | Sequencing advice | None | Priority |
| Implementation Planner | Technical plan | Draft evidence | Plan acceptance |
| Developer | Bounded implementation | Feature branch | PR/merge |
| Code Reviewer | Code risk | None | Human decides |
| PR Reviewer | Whole change package | None | Merge |
| Test Engineer | Test design | Draft evidence | UAT |
| Documentation Engineer | As-built | Docs branch | Merge |
| Change Prep | Change evidence | Draft only | CAB/change |
| Release Validator | Post-release validation | Evidence | Final acceptance |

Create a new agent only when responsibility/tools/gates are distinct. Otherwise add a Skill.
