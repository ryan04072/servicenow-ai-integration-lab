# Personal Lab — Integration Architect/Engineer

## Goal

Practice end-to-end integration research and design using your unrestricted
sandbox toolchain.

## Benchmark prompts

- "Connect ServiceNow to Teams for an interactive Adaptive Card workflow."
- "Create SharePoint content after a ServiceNow approval."
- "Create an Azure DevOps work item from an approved ServiceNow enhancement."
- "Query Entra for a user's governed access state."

## Expected behavior

For each:

1. inspect PDI/current implementation;
2. search official product knowledge;
3. identify OOB spoke/app;
4. determine PDI availability;
5. distinguish enterprise entitlement from personal availability;
6. design auth/identity;
7. derive permissions;
8. compare OOB / extend / custom;
9. create Integration Decision Packet;
10. request human context if required;
11. optionally implement in PDI;
12. run review/testing/documentation.
