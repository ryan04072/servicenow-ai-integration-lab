# Phased Build Roadmap

## Phase 0 — Merge and inventory

- [ ] Merge overlay.
- [ ] Inventory existing personal agents/skills.
- [ ] Inventory personal ServiceNow/GitHub/ADO integrations.
- [ ] Build capability registry.
- [ ] Define current auth.
- [ ] Define lab budget.

## Phase 1 — Read-only intelligence

Build:
- ServiceNow instance explorer;
- GitHub/repo explorer;
- Azure DevOps sprint/backlog explorer;
- executive/lab brief;
- roadmap alignment;
- historical delivery metrics.

## Phase 2 — Supervised writes

Allow:
- create/update ADO draft work items;
- create GitHub branch/PR;
- create DEV ServiceNow records/config through approved lab tools;
- draft documentation.

Keep approval for destructive operations.

## Phase 3 — Agent orchestration

Build:
- context router;
- architecture → engineer → reviewer → tester pipeline;
- multi-model review;
- feedback/precedent capture;
- run traces.

## Phase 4 — ServiceNow conversational IT lab

Prototype:
- Now Assist Panel / equivalent personal experience;
- incident assistant;
- analytics Q&A;
- knowledge-gap agent;
- problem-candidate agent;
- change advisor;
- identity-operations simulation.

## Phase 5 — Cross-platform capabilities

Expose one capability through multiple surfaces:

```text
Shared capability
→ ServiceNow agent
→ Copilot / another AI
→ API / n8n
```

Examples:
- create work item;
- retrieve incident context;
- generate change draft;
- simulate identity-access removal.

## Phase 6 — Autonomous lab workflows

Permit low-risk autonomous DEV actions:
- generate work item from intake;
- create feature branch;
- implement code/config;
- run tests;
- open PR;
- generate documentation.

Keep merge/destructive action manual.

## Phase 7 — Analytics and value

Track:
- runs;
- task success;
- token/API/assist usage where available;
- time saved;
- human correction;
- cost per successful run.

## Phase 8 — Portfolio/demo

Package 3–5 flagship demos:
1. AI-assisted SDLC
2. ServiceNow platform discovery
3. IT conversational assistant
4. executive analytics
5. cross-platform capability orchestration
