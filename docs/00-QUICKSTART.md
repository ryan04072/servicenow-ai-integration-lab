# Quickstart

## Day 1
1. Create a private GitHub repository.
2. Copy this package into it.
3. Open in VS Code.
4. Install only the extensions you intend to use.
5. Run `python scripts/validate_repo.py`.
6. Commit the foundation.

## Day 2
1. Copy `config/providers/providers.example.json` to `config/providers/providers.local.json`.
2. Leave providers in manual mode initially.
3. Create `LAB-001`.
4. Dispatch the first Intake Analyst prompt.
5. Run it manually in the provider of your choice.
6. Save the result into the work package.
7. Advance state only after review.

## First Month
- complete SDK basics lab,
- complete multi-provider review lab,
- validate DevOps Change Velocity evidence chain,
- establish 5–10 golden evals,
- automate only after manual quality is acceptable.
