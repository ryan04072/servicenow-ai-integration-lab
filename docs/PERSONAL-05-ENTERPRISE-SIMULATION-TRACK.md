# Personal Lab — Enterprise Simulation Track

## Purpose

This track is optional.

It lets the personal lab practice enterprise-grade motions such as:
- AI inventory;
- AI Control Tower;
- Copilot discovery/integration;
- ownership;
- value/cost;
- risk classification;
- lifecycle;
- audit/evidence;
- platform placement;

without making those controls blockers for normal experimentation.

## Rule

```text
Personal Experimentation
        │
        ├─ fast lab mode
        │
        └─ optional enterprise-simulation mode
                   ↓
          practice production patterns
```

Use enterprise-simulation mode when you specifically want to learn:

> "How would I operationalize this at work?"

Do not require it for:
- small throwaway experiments;
- model comparisons;
- PDI prototypes;
- disposable automation tests.

## Suggested enterprise simulation lifecycle

```text
Experiment
→ register as lab AI asset
→ assign yourself as owner
→ map capability
→ connect/discover in AI Control Tower where supported
→ classify risk
→ attach evidence
→ run
→ measure usage/cost/value
→ review
→ retire or promote
```

## Learning objective

The goal is not bureaucracy.

The goal is hands-on experience with the mechanics so that enterprise governance,
AI Control Tower, discovery, ownership, and lifecycle are familiar before you
have to implement them in a work environment.
