# Personal Lab — AI Build Documentation / Explainability

## Goal

Prove that an AI-built capability is still understandable months later.

For one end-to-end build, require the agents to produce:

1. AI Build Record.
2. Architecture Decision/Rationale Record.
3. GitHub technical as-built.
4. QRG/CRG/fulfiller KB draft if applicable.
5. Operational runbook if applicable.
6. Test/review evidence.

## Review exercise

Close the project, wait a few days, and answer using documentation only:

- Why did we select this architecture?
- What alternatives were rejected?
- Which evidence drove the decision?
- What did the AI actually change?
- Which human decisions mattered?
- How do we test it?
- How do we support it?
- How do we disable/rollback it?

If those cannot be answered, the documentation pipeline failed.
