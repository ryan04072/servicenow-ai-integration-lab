# Complete Personal Edition — Quickstart

## What this package contains

This is not just the 43-file overlay.

It includes:
- the canonical agent catalog;
- ServiceNow architecture/engineering agents;
- GitHub/Azure DevOps specialists;
- delivery-intelligence agents;
- context-routing framework;
- capability/tool contracts;
- MCP patterns;
- risk/autonomy models;
- security/authentication references;
- ServiceNow Now Assist/ITOM/analytics patterns;
- cross-platform AI placement;
- cost/value measurement;
- evals;
- orchestration pipelines;
- the personal experiment/lab layer.

## Start

1. Read `PERSONAL_MODE.md`.
2. Read `docs/00-QUICKSTART.md`.
3. Read `docs/03-PHASED-BUILD-ROADMAP.md`.
4. Configure `context/personal-lab/LAB_ENVIRONMENT.yaml`.
5. Review `config/personal-lab/lab-policy.yaml`.
6. Pick one experiment.
7. Build it.
8. Run tests/evals.
9. Open a PR.
10. Capture the result and move on.
