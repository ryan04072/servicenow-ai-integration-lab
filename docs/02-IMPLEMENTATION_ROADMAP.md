# Implementation Roadmap

## Phase 0 — Foundation
- repo instructions
- roles
- skills
- work-package schema
- lifecycle state machine
- evals

## Phase 1 — Manual Agent Lifecycle
- dispatch prompts manually
- require human transitions
- validate outputs against historical/simple tasks

## Phase 2 — SDK / PDI Engineering
- scoped SDK lab
- Fluent tooling
- Git workflow
- tests

## Phase 3 — Multi-Provider Review
- Provider A implements
- Provider B reviews
- Provider C creates adversarial tests
- human decides

## Phase 4 — GitHub Quality Automation
- foundation validation
- eval structural checks
- repository inventory
- project-specific SDK build workflow

## Phase 5 — DevOps Change Velocity Closed Loop
- confirm planning/coding/orchestration tool integrations
- collect work item / commit / test evidence
- automatic change where configured
- CAB/manual gate
- deployment result
- release manifest

## Phase 6 — Provider CLI Automation
- configure one provider at a time
- keep manual fallback
- fail closed if command or output fails

## Phase 7 — MCP / Live Tools
Only where native integrations do not already solve the problem.

## Phase 8 — Portfolio Product
Build a sanitized end-to-end demonstration project and technical write-up.
