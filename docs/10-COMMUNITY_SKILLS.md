# Community Skill / Plugin Governance

At home you can experiment, but downloaded skills are still executable instructions/code.

Before install/adoption inspect:
- instructions,
- scripts,
- hooks,
- MCP,
- network access,
- secrets/env access,
- package installs,
- license,
- update source.

Adoption levels:
1. Explore in isolated repo
2. Vendor/pin reviewed version
3. Promote to canonical after repeated value

Never give an unreviewed skill PDI admin credentials or GitHub write access.
