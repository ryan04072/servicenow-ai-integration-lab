# AI Utilization, Cost, and Value Measurement

## Executive principle

Do not equate:
- usage with adoption;
- adoption with quality;
- time saved with hard-dollar savings;
- low token cost with low total cost.

## Measurement stack

### Inventory
What exists?

### Utilization
- active users;
- actions/executions;
- conversations;
- skills/tools invoked;
- usage by department/persona;
- trend.

### Quality
- task completion;
- approval/edit/rejection rate;
- grounded/factual accuracy;
- tool success;
- safety/quality scores;
- failed actions;
- rework.

### Cost
- assists;
- tokens;
- platform licenses;
- vendor/model cost;
- runtime/integration cost;
- support/maintenance;
- human review.

### Value
- hours/capacity released;
- cycle-time reduction;
- cost avoidance;
- hard-dollar savings;
- revenue enablement;
- risk reduction;
- quality improvement;
- experience/adoption improvement.

## ServiceNow measurement

Use Now Assist Analytics / Assistant Analytics for detailed ServiceNow adoption,
skill/action usage and assist consumption where available.

Use AI Control Tower Value for portfolio-level productivity gains, AI cost, net
return, actions, and cost/value trends.

Use value templates to define value consistently.

AI Control Tower supports a productivity model based on:

```text
Usage × Time × Quality
```

For finance reporting, separately identify:
- capacity value;
- hard-dollar value;
- risk value;
- revenue/experience value.

Do not present all productivity hours as realized cash savings.

## Unit economics

Track where practical:
- cost per successful completion;
- cost per active user;
- cost per accepted AI action;
- human-review minutes per transaction;
- net value per capability.
