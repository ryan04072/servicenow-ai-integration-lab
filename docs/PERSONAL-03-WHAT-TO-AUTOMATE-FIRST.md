# What to Automate First

Prioritize experiments that are:

- reversible;
- easy to observe;
- rich in learning;
- low consequence;
- cross-disciplinary.

## High-value early automations

### 1. Intake → ADO
Teaches APIs, schemas, agent clarification, approvals, idempotency.

### 2. Work item → PR
Teaches architecture, code generation, testing, Git, review.

### 3. ServiceNow discovery
Teaches platform metadata, dependencies, MCP/API design.

### 4. Executive brief
Teaches deterministic analytics + AI narrative.

### 5. Shared capability
Teaches API/tool contracts and multi-surface AI design.

## Delay until later

- arbitrary autonomous script execution;
- general admin agents;
- public posting;
- financial transactions;
- real identity deletion;
- destructive infrastructure automation.

Those are useful later, but they are poor first learning targets because failure
cost dominates learning value.
