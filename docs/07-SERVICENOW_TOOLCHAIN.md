# ServiceNow Toolchain

## VS Code
Use for:
- Git
- Copilot / Claude / Codex / Gemini
- SDK / Fluent
- source review
- local scripts / tests
- documentation

## ServiceNow Native
Use Studio / IDE / Workflow Studio where appropriate for:
- native metadata/config
- flows/subflows/actions
- global/OOB extension
- live instance work

## SDK / Fluent
Use for source-driven scoped development where supported.

## Build Agent / Test Agent
If available in the PDI/release, compare native instance-aware AI against external coding agents.

The lab should teach **tool choice**, not force every artifact into one development model.
