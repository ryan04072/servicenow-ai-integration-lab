# Autonomy Promotion Checklist

Before promoting a workflow to the next autonomy level:

- [ ] Current level has sufficient test runs
- [ ] Factual accuracy meets agreed threshold
- [ ] Missing-context behavior is acceptable
- [ ] Tool failures are handled safely
- [ ] Audit trace is complete
- [ ] Human reviewers understand override path
- [ ] Rollback/disable mechanism exists
- [ ] Security review completed where required
- [ ] Data policy/identity confirmed
- [ ] Evals pass
- [ ] Scope is bounded
- [ ] Production write remains prohibited unless separately governed
