# AI Value & Cost Review Checklist

- [ ] Usage available
- [ ] Active-user adoption available
- [ ] Quality/task-success available
- [ ] Assist/token/vendor cost available
- [ ] Human review cost considered
- [ ] Support/maintenance cost considered
- [ ] Capacity hours estimated
- [ ] Hard-dollar value separately identified
- [ ] Risk/quality value documented if material
- [ ] Cost per successful completion calculated where possible
- [ ] Underused paid capability identified
- [ ] Duplicate capability cost checked
- [ ] Expand/optimize/hold/consolidate/retire decision recorded
