# New Integration Security Gate

Before creating credentials:

- [ ] Use case documented.
- [ ] Source/target documented.
- [ ] READ operations listed.
- [ ] WRITE operations listed.
- [ ] Operations not needed listed.
- [ ] Data classification known.
- [ ] Preferred authentication selected.
- [ ] Fallback authentication selected.
- [ ] Security/Identity review performed if required.
- [ ] Dedicated non-human identity used for unattended automation.
- [ ] Least privilege validated.
- [ ] DEV/UAT/PROD separation considered.
- [ ] Secret-free/federated mechanism evaluated.
- [ ] Credential store approved.
- [ ] Rotation/revocation defined.
- [ ] Audit/logging defined.
- [ ] Kill switch defined.
- [ ] Retry/idempotency defined for writes.
- [ ] Human approval boundary defined.
- [ ] Migration/remediation item created for any temporary legacy authentication.
