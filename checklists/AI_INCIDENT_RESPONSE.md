# AI Incident Response Checklist

- [ ] Correlation/run ID captured
- [ ] AI asset identified
- [ ] Capability/tool identified
- [ ] Affected users/data/process identified
- [ ] Kill switch / containment considered
- [ ] Existing operational/security/privacy incident opened as required
- [ ] AI case opened/correlated where applicable
- [ ] AI asset owner notified
- [ ] Platform/capability owner notified
- [ ] Security/privacy notified if applicable
- [ ] Human fallback activated
- [ ] Root cause completed
- [ ] Incorrect actions reversed where safe
- [ ] Eval/test gap added
- [ ] Risk/autonomy reassessed
- [ ] Re-approval performed if material
- [ ] Preventive action documented
