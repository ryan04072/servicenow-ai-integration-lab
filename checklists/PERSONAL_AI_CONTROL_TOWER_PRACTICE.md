# Personal AI Control Tower Practice Checklist

This checklist is optional.

- [ ] AICT available in personal lab
- [ ] Copilot connection/discovery reviewed
- [ ] One AI asset identified
- [ ] One AI asset owner assigned
- [ ] Capability ID linked
- [ ] Repository reference linked
- [ ] Provider/runtime documented
- [ ] Autonomy level documented
- [ ] Kill switch documented
- [ ] Risk level recorded
- [ ] Usage captured
- [ ] Cost captured where available
- [ ] Value hypothesis recorded
- [ ] Run trace compared to AICT record
- [ ] Simulated failure practiced
- [ ] Retirement practiced
- [ ] Lessons documented
