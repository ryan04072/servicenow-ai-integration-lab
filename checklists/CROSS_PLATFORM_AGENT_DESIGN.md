# Cross-Platform Agent Design Checklist

Before building a custom AI agent:

- [ ] What business outcome does it own?
- [ ] Which platform is the system of record?
- [ ] Which platform is the system of action?
- [ ] Where does the primary user work?
- [ ] Does an OOB agent/skill already exist?
- [ ] Does another team already have the same capability?
- [ ] Can the business capability be exposed as a reusable API/action/MCP tool?
- [ ] Would building here duplicate logic elsewhere?
- [ ] Is connector-indexed context sufficient?
- [ ] Is live transactional context required?
- [ ] Are native permission semantics required?
- [ ] What is the cost model?
- [ ] What is the human gate?
- [ ] Crawl stage defined?
- [ ] Walk stage defined?
- [ ] Run stage defined?
- [ ] Success measures defined?
- [ ] Capability owner defined?
