# Internal IT Now Assist Setup Checklist

## Experience
- [ ] Service Operations Workspace is the primary fulfiller experience.
- [ ] Now Assist Panel is enabled for intended personas.
- [ ] Roles are correctly scoped.
- [ ] Panel behavior is tested with least-privilege fulfiller users.

## ITSM
- [ ] Incident summarization validated.
- [ ] Change summarization validated.
- [ ] Resolution-note generation validated.
- [ ] Knowledge drafting validated.
- [ ] Recommended Actions validated.
- [ ] AI Search grounding validated.

## Analytics
- [ ] Analytics Q&A available.
- [ ] Query Generation configured.
- [ ] Supported facts/tables reviewed.
- [ ] Visualization-generation skill enabled.
- [ ] KPI catalog established.
- [ ] Executive questions tested.

## ITOM
- [ ] Alert analysis validated.
- [ ] Alert/incident impact investigation validated.
- [ ] Observability integrations reviewed.
- [ ] AI agents/agentic workflows inventoried.
- [ ] ITOM MCP reviewed if supported/entitled.

## Customization
- [ ] OOB capability checked first.
- [ ] Custom agent has explicit gap statement.
- [ ] Tools are least privileged.
- [ ] Structured output/evals defined.
- [ ] Human gates defined.
- [ ] Owner/support runbook defined.

## Analytics/Adoption
- [ ] Now Assist Analytics reviewed.
- [ ] Assistant Analytics reviewed if available.
- [ ] Adoption baseline defined.
- [ ] Assist consumption monitored.
